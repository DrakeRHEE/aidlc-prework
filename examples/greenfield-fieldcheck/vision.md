# Vision: 그린마트 현장 점검 (fieldcheck)

## Summary

그린마트 현장 점검은 본사 슈퍼바이저가 매장 점검표를 작성해 제출하면 점수를 자동으로 계산하고, 미흡 항목을 점주 조치 요청으로 바로 넘기는 점검 시스템이다.
지금은 슈퍼바이저 20명이 매장 300곳을 돌며 위생, 진열, 유통기한을 종이 점검표에 적고, 사진을 따로 찍은 뒤 엑셀에 다시 옮기고, 점주에게 메일로 조치를 요청한다.
점검표 작성, 사진 첨부, 점수 계산, 조치 요청을 한 흐름으로 묶어 이 문제를 해결한다.
기대 결과는 점검표를 제출하는 순간 점수와 조치 요청이 함께 생성되어, 엑셀 재입력과 조치 요청 메일 작성 단계가 0건이 되는 것이다.

## Target Users

| User Type | Description | Primary Need |
|-----------|-------------|--------------|
| 슈퍼바이저 | 본사 소속으로 매장을 돌며 점검하는 담당자 | 현장에서 점검표와 사진을 한 번에 기록하고, 점수와 조치 요청이 자동으로 만들어지는 것 |
| 점주 | 점검을 받는 가맹점 운영자 | 자기 매장의 미흡 항목과 증거 사진을 확인하고 조치 완료를 알리는 것 |

## Success Criteria

- [ ] 슈퍼바이저가 위생 항목 1개를 미흡으로 체크하고 사진을 첨부해 제출하면 점수가 표시되고, 그 항목이 사진과 함께 해당 매장 점주의 조치 요청 목록에 "요청됨" 상태로 나타난다
- [ ] 점수 계산에 위생 항목 배점 2배가 반영되고, 70점 미만이면 "재점검 대상"으로 표시되며 70점 이상이면 표시되지 않는다
- [ ] 점주가 조치 요청에서 "조치 완료"를 누르면 상태가 "요청됨"에서 "조치완료"로 바뀌고, 슈퍼바이저 화면에서도 바뀐 상태가 보인다
- [ ] 점주는 다른 매장의 조치 요청을 볼 수도, 처리할 수도 없다

## In Scope (First Release)

| Feature | Description | Why it cannot wait |
|---------|-------------|--------------------|
| 점검표 작성과 제출 | 매장을 고르고 위생, 진열, 유통기한 항목을 적합 또는 미흡으로 체크해 제출 | 모든 흐름의 출발점 |
| 사진 첨부 | 항목별로 사진을 첨부해 점검 기록과 함께 보관. 미흡 항목이어도 사진은 선택 | 미흡 항목의 증거. 지금은 사진을 따로 관리하는 것이 가장 큰 번거로움 |
| 점수 자동 계산 | 위생 항목 배점 2배로 점수를 계산하고, 70점 미만이면 "재점검 대상"으로 표시 | 엑셀 재입력을 없애는 핵심이자 데모 장면 |
| 조치 요청 자동 생성 | 제출할 때 미흡 항목마다 해당 매장 점주에게 보낼 조치 요청을 생성 | 메일 작성을 없애는 핵심이자 데모 장면 |
| 조치 요청 목록과 조치 완료 처리 | 점주가 자기 매장의 조치 요청만 보고 "조치 완료"로 바꿈 ("요청됨 → 조치완료" 2단계) | 점검에서 조치까지 흐름을 끝까지 닫는 데 필요 |

## Out of Scope

| Feature | Why it can wait |
|---------|-----------------|
| 본사 대시보드 | 두 번째 사용 흐름이고, 점검 데이터가 쌓인 뒤에야 의미가 있음 |
| 점주 알림톡 발송 | 외부 연동이 필요함. 1차는 점주가 화면에서 조치 요청을 확인 |
| 슈퍼바이저 일정 관리 (재점검 일정 포함) | 별도 사용 흐름. 1차는 "재점검 대상" 표시까지만 |
| 점주 전용 모바일 앱 | 1차는 설치 없이 열리는 화면으로 대체 |
| 슈퍼바이저 조치 확인 단계 | 1차는 상태를 2단계로 단순화. 3단계(확인완료)는 나중에 추가 |
| 정식 로그인과 권한 관리 | 1차는 역할별 고정 사용자로 대체 |
| 실제 매장 300곳 데이터 이관 | 1차는 샘플 매장 데이터로 검증 |
