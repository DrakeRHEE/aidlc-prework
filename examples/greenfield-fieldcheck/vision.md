# Vision: FieldCheck

## Summary

FieldCheck는 편의점 프랜차이즈 '그린마트'(실습용 가상 이름) 본사 슈퍼바이저가 매장 점검표를 작성해 제출하면, 점수가 자동으로 계산되고 미흡 항목이 점주 조치 요청으로 바로 넘어가게 하는 매장 점검 시스템이다.
지금은 슈퍼바이저 20명이 매장 300곳을 돌며 위생, 진열, 유통기한을 종이 점검표에 적고, 엑셀로 옮긴 뒤 메일로 점주에게 조치를 요청한다.
점검 제출 한 번으로 점수 계산과 조치 요청 생성을 끝내서 엑셀 옮기기와 메일 발송 단계를 없앤다.
점주는 자기 매장의 조치 요청을 시스템에서 확인하고 완료 처리한다.

## Target Users

| User Type | Description | Primary Need |
|-----------|-------------|--------------|
| 슈퍼바이저 | 매장을 돌며 위생, 진열, 유통기한을 점검하는 본사 직원 | 현장에서 점검표를 바로 입력하고 제출하면 점수와 조치 요청이 자동으로 처리되는 것 |
| 점주 | 매장을 운영하는 가맹점주 | 자기 매장의 조치 요청을 확인하고 완료를 알리는 것 |

## Success Criteria

- [ ] (데모 장면) 슈퍼바이저가 매장 하나의 점검표를 제출하면 점수와 '재점검 대상' 여부가 화면에 표시되고, 미흡 항목이 해당 매장 점주의 조치 요청으로 생성된다
- [ ] 위생 항목은 다른 항목의 2배 배점으로 계산되고, 총점이 70점 미만이면 '재점검 대상'으로 표시된다
- [ ] 미흡 항목 하나당 조치 요청이 1건씩 생성된다 (미흡이 없으면 조치 요청은 생성되지 않는다)
- [ ] 점주는 자기 매장의 조치 요청만 조회하고 완료 처리할 수 있으며, 다른 매장의 조치 요청을 요청하면 거부된다

## In Scope (First Release)

| Feature | Description | Why it cannot wait |
|---------|-------------|--------------------|
| 점검표 작성과 제출 | 슈퍼바이저가 매장을 고르고 위생, 진열, 유통기한 항목별로 적합/미흡을 체크해 제출 | 데모 장면의 시작점이고, 종이 점검표를 대체하는 핵심 기능 |
| 점수 자동 계산 | 제출 시 위생 항목 배점 2배로 총점을 계산하고, 70점 미만이면 '재점검 대상'으로 표시 | 엑셀로 옮겨 수작업으로 계산하는 단계를 없애는 확정 규칙 |
| 조치 요청 자동 생성 | 제출된 점검의 미흡 항목마다 해당 매장 점주의 조치 요청을 생성 | 메일로 조치를 요청하는 단계를 없애는 데모 장면의 끝 |
| 점주 조치 요청 확인과 완료 | 점주가 자기 매장의 조치 요청 목록을 보고 '완료' 처리 | 요청에서 완료까지 흐름이 닫히는 것을 보여 준다 |

## Out of Scope

| Feature | Why it can wait |
|---------|-----------------|
| 사진 첨부 | 점수 계산과 조치 요청 흐름은 사진 없이도 동작한다. 파일 처리가 들어가면 하루 일정이 빠듯하다 |
| 본사 대시보드 | 점검 데이터가 쌓인 뒤에 의미가 있는 두 번째 흐름이다 |
| 카카오 알림톡 | 외부 연동이고 사전 승인 절차가 필요하다. 1차는 조치 요청이 시스템 안에 생성되는 것까지만 한다 |
| 슈퍼바이저 일정 관리 | 점검 흐름과는 별개의 사용 흐름이다 |
| 점주 모바일 앱 | 같은 흐름을 웹 화면으로 먼저 검증할 수 있다 |
| 정식 로그인과 계정 관리 | 1차는 미리 정한 고정 사용자(슈퍼바이저, 점주)로 진행한다. 매장별 조회 제한은 1차에도 지킨다 |
| 실제 매장과 슈퍼바이저 전체 데이터 | 1차는 샘플 데이터(매장 몇 곳)로 검증한다 |

## Open Questions

- [ ] 점검 항목 목록과 개수 (위생, 진열, 유통기한 카테고리별로 몇 개인지)
- [ ] 항목별 기본 배점과 100점 만점 환산 방식 (위생 2배를 적용한 뒤 어떻게 100점으로 맞추는지)
- [ ] 판정 방식: 적합/미흡 2단계로 충분한지, 단계별 점수가 필요한지
- [ ] '재점검 대상' 표시 이후의 처리 (1차는 표시만 하는지)
- [ ] 조치 요청에 처리 기한이나 점주 완료 메모가 필요한지
