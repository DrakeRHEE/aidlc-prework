# Vision: LibraryHub 도서 예약 기능

## Summary

LibraryHub는 사내 도서를 대여하고 반납하는 기존 API 서비스다. 이번 작업은 대여 중인 책에
**예약(대기열)** 기능을 추가한다. 지금은 원하는 책이 대여 중이면 직원이 메신저로 대여자에게
직접 물어봐야 해서, 인기 도서는 반납 후에도 몇 주씩 다음 사람에게 넘어가지 못한다.
반납 시 대기열 첫 번째 사람에게 자동으로 대여 우선권을 주는 방식으로 해결한다.
기대 결과는 인기 도서가 반납된 뒤 다음 대여까지 걸리는 시간을 평균 1일 이내로 줄이는 것이다.

## Target Users

| User Type | Description | Primary Need |
|-----------|-------------|--------------|
| 직원 | 책을 빌리는 사내 직원 | 대여 중인 책을 예약하고 내 순번 확인 |
| 도서 담당자 | 대여와 반납을 처리하는 1명 | 반납 시 다음 예약자 확인 |

## Success Criteria

- [ ] 데모: 대여 중인 책을 직원 A와 B가 차례로 예약하고, 반납되면 A에게 48시간 우선권이 생긴다
- [ ] 대여 가능한 책은 예약할 수 없고 400 응답과 이유가 반환된다
- [ ] 기존 대여/반납 API의 테스트가 모두 그대로 통과한다

## In Scope (First Release)

| Feature | Description | Why it cannot wait |
|---------|-------------|--------------------|
| 예약 생성 | `POST /books/{id}/holds`, 대여 중인 책만 예약 가능, 1인 1건 | 핵심 기능 |
| 내 예약 조회와 취소 | `GET /me/holds`, `DELETE /holds/{id}`, 순번 포함 | 사용자가 상태 확인 |
| 반납 시 우선권 부여 | 반납 처리 후 대기열 1순위에게 48시간 우선권 | 문제의 핵심 해결 |

## Out of Scope

| Feature | Why it can wait |
|---------|-----------------|
| 이메일/메신저 알림 | 외부 연동 없이 흐름 검증이 우선 |
| 우선권 만료 자동 처리 배치 | 1차는 조회 시점에 만료 판정으로 대체 |
| 웹 UI | 기존 서비스도 API 전용 |

## Current State

LibraryHub는 FastAPI 기반 REST API로, 도서 목록 조회, 대여(`POST /loans`), 반납
(`POST /loans/{id}/return`)을 제공한다. PostgreSQL에 `books`, `loans` 테이블이 있고,
사내 인증 게이트웨이가 넣어 주는 `X-Employee-Id` 헤더로 사용자를 식별한다.

## Must Not Change

- 기존 `/loans` API의 요청/응답 형식 (다른 사내 시스템이 호출 중)
- `books`, `loans` 테이블의 기존 컬럼 (새 테이블 추가만 허용)
- `app/auth/` 모듈의 사용자 식별 방식
