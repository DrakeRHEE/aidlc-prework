# Vision: RoomBook

## Summary

RoomBook은 사내 직원이 회의실을 웹에서 조회하고 예약할 수 있게 하는 사내용 웹 애플리케이션이다.
지금은 공유 엑셀 시트로 예약을 관리해서 중복 예약이 주 2~3회 발생하고, 빈 회의실을 찾는 데 시간이 든다.
예약할 때 시간 충돌을 자동으로 막고, 남은 시간대를 한 화면에서 보여 주는 방식으로 해결한다.
기대 결과는 중복 예약 0건과, 빈 회의실 확인부터 예약까지 1분 이내다.

## Target Users

| User Type | Description | Primary Need |
|-----------|-------------|--------------|
| 직원 | 회의를 잡는 모든 직원 | 원하는 시간에 빈 회의실을 빨리 찾고 예약 |
| 총무 담당자 | 회의실 목록을 관리하는 1~2명 | 회의실 정보(이름, 수용 인원) 등록 |

## Success Criteria

- [ ] 데모: 직원이 날짜를 고르면 회의실별 빈 시간대가 보이고, 한 시간대를 예약하면 목록에 즉시 반영된다
- [ ] 이미 예약된 시간과 겹치는 예약 요청은 거부되고 이유가 표시된다
- [ ] 본인 예약을 취소하면 해당 시간대가 다시 비어 보인다

## In Scope (First Release)

| Feature | Description | Why it cannot wait |
|---------|-------------|--------------------|
| 회의실 목록 | 회의실 이름, 수용 인원 조회 (시드 데이터) | 예약의 기준 데이터 |
| 날짜별 빈 시간대 조회 | 30분 단위 시간대를 회의실별로 표시 | 핵심 사용 흐름의 시작 |
| 예약 생성 | 회의실, 시작/종료 시각, 제목 입력. 충돌 시 거부 | 핵심 문제(중복 예약) 해결 |
| 내 예약 조회와 취소 | 고정 사용자 기준 본인 예약 목록과 취소 | 잘못된 예약 정정 |

## Out of Scope

| Feature | Why it can wait |
|---------|-----------------|
| 사내 SSO 로그인 | 1차는 고정 사용자로 흐름 검증이 목적 |
| 반복 예약(매주 회의) | 단건 예약으로 충돌 방지를 먼저 검증 |
| 캘린더(Outlook/Google) 연동 | 외부 연동 없이 핵심 가치 확인 |
| 회의실 등록/수정 관리자 화면 | 시드 데이터로 대체 가능 |
